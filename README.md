# games

A collection of small, dependency-free browser games. Each one lives in its own
folder and runs by opening its `index.html` — no build step, no install.

| Game | Folder | What it is |
| --- | --- | --- |
| **Froggy Pursuit** | [`froggy-pursuit/`](froggy-pursuit/) | Endless highway escape: swerve through traffic while the police close in |

`index.html` at the repo root is a small hub that links to them, so the whole
repo can be published with GitHub Pages as-is.
